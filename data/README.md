# RetailOps 360 — Databricks source dataset

This package contains **8 CSV datasets (311,025 rows)**, a data model, a reproducible generator, and a Databricks SQL table setup script. It is designed for the Phase 1 JOINs/relationships SQL case study and a Databricks AI/BI dashboard.

## Suggested Databricks namespace

`retailops360.source`

## Load instructions

1. Create the `retailops360` catalog and `source` schema if they do not exist.
2. Create a Unity Catalog volume in `retailops360.source` (e.g. `source_files`).
3. Upload all eight CSV files from `data/` into that volume (Databricks Catalog Explorer → volume → Upload).
4. Run [the setup script](../scripts/setup_databricks.sql) in Databricks SQL. The script creates the eight Delta tables and has COPY INTO commands with a replaceable volume path.
5. Check counts with the validation query at the end of the SQL script.

The data is synthetic, deterministic (fixed random seed), and generated by [the generator](../scripts/generate.py). Do not treat sample data as genuine financial results.
